占名额的电脑。管理员可从租户台账点「查看电脑」只看该户。吊销或插件「释放名额」才空出名额。换到别的 Relay 不必先在这里吊销。已吊销折起，清理只删那些记录。

邀请记录

未用码和仍占名额的已接入记录在主表。失效折起；清理不会删掉还能对照吊销电脑的已用码。

操作记录

谁签发或吊销了邀请与 Host，以及控制台登录成败。电脑名会写入，不含接入码、密码或会话内容。

匿名设备

自助接入的设备（公钥指纹为身份）。禁用即级联吊销其全部 Host。

管控租户

维护者开通。config 填写 public_control_url（HTTPS 反代地址）后，开通即可把该地址交给租户。已接入或未用码满额的排在前面，对方自己登录去吊销或签发。回环 127.0.0.1 不要外发。隔离邀请与 Host，不是 App 账号，也不是公开注册。停用后可恢复，已吊销 Host 不会自动回来。

未配置 public_control_url：在回环开通租户时无法自动交出登录地址。托管请填写指向 127.0.0.1:8080 的 HTTPS 反代 URL 后重启 control。不要把 8080 暴露到公网，也不要开放注册。

修改密码

只改控制台登录。维护者发的初始密码或重置密码，登录后必须先改这一次。手机 App 不走这里。
