## 实施目标

按你确认的 1–6 顺序完成，保留 DeepHarness 现有 DSH 暗色视觉，不照搬 NameThatUI 的网页样式。实施采用渐进式改造；每一项先完成、编译与测试通过，再进入下一项，避免同时重写 `WorkspaceActivity` 的状态架构。

## 1. 恢复并完善会话搜索

- 在主工作区增加明确可达的“搜索/历史”入口，复用现有 `HistoryView` 和 `/mobile/sessions/search`，不新增服务端接口。
- 将搜索请求改为约 250ms 防抖、可取消的查询驱动流程，阻止旧请求覆盖新结果。
- 明确区分加载、无结果、错误、最近会话四种状态；无结果提供“清除搜索/查看全部”恢复动作。
- 选择结果时只更新 `currentSessionId`，移除重复的消息刷新调用。
- 保存视图模式和查询文本，但不保存远端搜索结果；恢复后重新请求。
- 默认把它定义为“全局历史搜索”，可检索服务端仍保留的会话；抽屉中的归档/隐藏规则不改变搜索结果语义。

## 2. 将断线提示升级为 Connection Banner

- 扩展 `SessionStreamClient` 的连接状态，不再只暴露 Boolean：至少区分首次连接、已连接、退避重连和失败原因。
- 提供安全的手动 `reconnect()`，取消旧连接循环后立即重新连接。
- 用统一 DSH Banner 呈现重连状态、失败原因和“立即重试”动作；成功恢复时给出短暂“已重新连接”反馈。
- 保持现有轮询兜底与 SSE 去重机制，不改变消息协议。
- 为 Banner、旋转指示和动作增加 TalkBack live-region、按钮角色与状态描述。
- 对当前静默吞掉的发送失败补充可见反馈，并确保不会错误宣称消息已发送。

## 3. 将斜杠建议演进为统一 Command Palette

- 把嵌套 `Pair` 命令表替换为带稳定 ID、分类、关键词和动作类型的模型。
- 保留 `/` 输入触发，同时增加全局入口；第一版继续使用现有静态命令和本地操作，不虚构动态命令接口。
- 支持命令、会话搜索、新会话、打开设置、切换视图、模型和权限选择等动作。
- 完整命令可直接提交；需要参数的 `/plan`、`/goal`、`/subagent` 只插入输入框并恢复焦点。
- 使用有高度上限的 `LazyColumn`，增加分组、空状态、返回键关闭、焦点恢复和 IME 组合输入保护。
- 让 Palette 状态显式化，避免它仅由 `inputText.startsWith("/")` 隐式控制。

## 4. 统一 Badge / Chip / Tag / Banner / Toast 语义

- 建立可复用的 DSH 基础组件：
  - `DshFilterChip`：可选择筛选；
  - `DshTag`：只读状态/分类；
  - `DshBadge`：附着数量或紧凑状态；
  - `DshBanner`：持续影响当前界面的状态；
  - Snackbar/Toast 规则：短暂操作反馈用 Snackbar，跨 Activity 或系统级反馈保留 Toast。
- 首批迁移会话筛选、模式切换、停止状态、轨迹角色标签、重连提示和设备离线提示；不做全项目一次性视觉重写。
- 统一选中语义、按钮角色、live region、非纯颜色状态提示和最小触控范围。
- 只复用现有 `Dsh` token；必要状态色通过语义 token 补齐，不引入第三方视觉。

## 5. 建立 Compose 组件目录与 Preview，并安全拆分巨型文件

- 先抽取纯逻辑和通用组件，再移动低耦合 Composable；不拆 `WorkspaceScreen` 状态持有者，不在本轮引入 ViewModel 大重构。
- 优先拆出：筛选与基础状态组件、Banner/Tag/Chip、对话框、Picker、统计、搜索、轨迹、输入栏、消息行、Markdown 和工具卡。
- 跨文件符号使用 `internal`，不扩张公开 API。
- 增加按 filters / feedback / messages / composer / dialogs 分组的 `@Preview` 目录，使用固定假数据并包裹 `DshTheme`。
- 补齐 `ui-tooling-preview` 依赖；不强制引入截图测试框架。
- 为 `groupMessages`、会话分类、Palette 过滤等纯函数增加 JVM 单元测试。

## 6. 增加工具调用搜索、筛选持久化与加载骨架

- 将 `MessageGroup` / `groupMessages` 抽成可测试纯逻辑，并保持现有相邻工具调用聚合行为。
- 增加当前会话的工具查找入口，匹配 `toolName`、参数和结果文本；结果保留必要上下文，不改变服务端协议。
- 将会话状态筛选与平铺/分组选择写入现有 `dsh_workspace` SharedPreferences，并封装成 `WorkspacePrefs`；工具查询保持瞬时，不持久化。
- 为首次会话消息加载增加与真实布局近似的 Skeleton，约 200ms 延迟出现，加载/空白/错误互斥，并遵守减少动态效果设置。
- 不在本轮增加工具调用后端索引或基于 `callId` 的协议变更。

## 验证标准

每个阶段至少执行快速 Kotlin 编译；最终执行：

1. `./gradlew :app:testDebugUnitTest`
2. `./gradlew :app:assembleDebug`
3. `./gradlew :app:lintDebug`

如 Android 模拟器环境可用，再安装启动，逐项验证：搜索快速输入不串结果、重连/手动重试、命令插入与直发差异、筛选重启后保留、工具搜索、Skeleton 和 TalkBack 语义。测试或 lint 若存在原有失败，会明确区分新增回归与既有问题。
