# DeepSeek Harness 移动端界面缺陷深度优化与 1:1 复刻完善方案

通过对用户反馈的 6 处核心问题（状态栏白色被吞没、顶栏/引导区/输入框细节对齐、会话下拉弹窗视觉畸变、设置页 Select 浮层体验优化、会话轨迹/执行轨迹展示缺失）进行代码审查，制定本修复执行方案。

---

## 问题清单与解决计划

### 1. 状态栏沉浸式与图标颜色动态适配（解决图 1、图 2 浅色模式下状态栏电量/时间看不清问题）
- **根因**：各 Activity (`MainActivity`, `SplashActivity`, `DevicesActivity`, `WorkspaceActivity`, `SettingsActivity`) 在 `enableEdgeToEdge` 时硬编码了 `SystemBarStyle.dark`，在白色浅色背景下状态栏图标仍为白色。
- **改动**：
  - 在 `DshTheme.kt` 中通过 `LocalView` 与 `WindowCompat.getInsetsController(window, view)` 实现全局响应式状态栏管理：
    - 当 `isDark == true`（深色模式）时：`isAppearanceLightStatusBars = false`（状态栏图标与文字呈现白色/浅色）；
    - 当 `isDark == false`（浅色模式）时：`isAppearanceLightStatusBars = true`（状态栏图标与文字呈现深黑色），彻底解决浅色模式下状态栏被白色吞没的问题。
    - 状态栏背景色统一为透明或融入主背景 `Dsh.bgBase`。

---

### 2. 工作台 1:1 对齐 DeepSeek Harness Web 设计规范（解决图 2 标红区域不匹配问题）
- **顶栏（Header Bar）**：
  - **标签切换与面包屑**：对齐 DSH Web 规范，支持「对话」与「历史 / 轨迹」切换；
  - 面包屑区域保持紧凑设计（高度 32dp，标题 14sp Medium，单行省略）；
  - 增加细微的 1px 底边框 `Dsh.borderL1` 分隔线。
- **中间 Hero 引导区（HeroShell）**：
  - 优化品牌图标（DSH Badge）与模式切换胶囊（`对话` / `计划` / `目标`），使背景、选中态高亮与边框 1:1 对齐 DSH 设计（未选中为微灰透，选中为 `Dsh.bgNavActive` 或 `Dsh.hover`）。
- **底部输入工具条（InputBar）**：
  - 严格还原 DSH Web 输入框工具条：权限胶囊（`完全访问 ⌄`）、相册图标、麦克风图标、模型胶囊（`mimo-v2.5 ⌄`）、发送按钮（圆角与品牌蓝高亮）。
  - 各工具项之间的 padding、间距以及高度对齐规范（容器 22dp 圆角，背景色 `Dsh.bgInput`）。

---

### 3. 会话更多操作浮层优化（解决图 2 / 图 3 重命名、分叉会话、归档弹窗不对的问题）
- **根因**：当前使用默认的 `DropdownMenu`，锚点计算偏向左侧，且缺少 DSH 样式圆角边框、菜单图标和统一内边距。
- **改动**：
  - 重构 `SessionRowItem` 和顶栏会话操作菜单；
  - 为每个菜单项补充标准图标与清晰文字（重命名 ✏️、分叉会话 🔀、归档/取消归档 📦）；
  - 菜单背景统一采用 `Dsh.bgLayer1` / `Dsh.bgCard`，带细边框 `Dsh.borderL2` 与 12dp 圆角，阴影和层级立体感更协调。

---

### 4. 设置页小弹窗/下拉选择器全量重构（解决图 4、图 5 下拉浮层粗糙偏左问题）
- **根因**：`SettingsSelectItem` 使用默认 `DropdownMenu`，在手机宽屏或全屏行点击时弹出窄长框，视觉偏左且无选中状态指示。
- **改动**：
  - 将 `SettingsSelectItem`（语言、主题、Enter 行为、工作区访问模式）重构为符合移动端人机交互标准的 **DSH 风格底部抽屉选择器（ModalBottomSheet / BottomSheetSelect）** 或 **居中选择弹窗**；
  - 选项行高 48dp~52dp，选中项右侧展示品牌蓝勾选图标 `✓`（`Icons.Default.Check`），具备明确的按压与激活状态；
  - 统一深浅色主题下的背景与文字层级。

---

### 5. 会话轨迹（Trace / Trajectory / Timeline）全量支持（解决图 6 红色框对话轨迹未显示问题）
- **根因**：当前移动端仅有「对话」与「历史」，未将 DSH Web 中的「轨迹」独立为视图模式，底部的轮次/步骤/Token 统计也缺少全量信息栏。
- **改动**：
  - **顶栏 Tab 扩展**：支持 `listOf("chat" to "对话", "trace" to "轨迹", "history" to "历史")` 三态切换，亦可在单会话顶栏支持「对话 / 轨迹」切换；
  - **轨迹时间轴（TrajectoryView）**：
    - 结构化过滤并展示当前会话的每一个执行步骤：用户目标、思考过程（Reasoning）、工具调用（Tool Call）、执行返回结果（Tool Result）与最终回答；
    - 左侧带竖向连接线与序号节点，右侧展示工具名、耗时与参数；
  - **底部状态统计条（StatsLine）**：
    - 1:1 复刻 DSH Web 底栏统计：`X 轮 · Y 步 | LLM 耗时 · 工具耗时 | 首 token / 吞吐 | 缓存命中率 | 输入 / 输出 Tokens`。

## 涉及修改的文件
1. `app/src/main/java/dev/dsh/mobile/DshTheme.kt`：增加全局 Window 状态栏图标亮暗色动态控制。
2. `app/src/main/java/dev/dsh/mobile/WorkspaceActivity.kt`：
   - 优化顶栏 Header、Hero 引导区、底部 InputBar 样式；
   - 增加「轨迹 / Trace」视图组件与时间轴渲染；
   - 优化底部 StatsLine 统计栏展示与更多操作菜单。
3. `app/src/main/java/dev/dsh/mobile/SettingsActivity.kt`：
   - 重构所有 `SettingsSelectItem`，替换为 DSH 风格移动端选项抽屉/弹窗（带 Checked Indicator）。
4. `app/src/main/java/dev/dsh/mobile/DevicesActivity.kt`：状态栏动态适配与弹窗样式对齐。

1. 编译并打包安装到模拟器 `emulator-5554`。
2. **测试状态栏**：分别切换浅色与深色主题，验证状态栏时间、电量图标在深浅背景下清晰可见。
3. **测试工作台与轨迹**：验证对话视图与轨迹视图切换、每步工具调用展示、底部状态行显示。
4. **测试弹窗与设置**：验证重命名、分叉会话弹窗，以及设置页所有语言、主题、Enter 键行为选项弹窗的居中与勾选指示。
