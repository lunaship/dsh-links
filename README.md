# DSH Links（总仓）

三个并列项目：

| 目录 | 是什么 | 源码 |
|---|---|---|
| [`app/`](app/) | Android 客户端（Android Studio 工程根） | 闭源；Release 只发签名 APK |
| [`dsh-links/`](dsh-links/) | DSH 电脑端插件（npm）+ 手机 API | 开源 MIT |
| [`dsh-links-relay/`](dsh-links-relay/) | 自建远程中继（规划中） | 后续自建；现为占位与实验笔记 |

```
dsh-links/                 ← 你现在打开的总目录
├── app/                   ← 手机 App
├── dsh-links/             ← 插件
└── dsh-links-relay/       ← 中继（待建）
```
