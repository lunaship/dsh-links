# Web 工作台观察记录（Gate 5：14 天）

> 从开始把 Web 工作台当日常使用的那天起记录。数据决定 Gate 6（归档原生工作台）是否执行。

| 指标 | 通过 | 不通过（回退 native，继续修 Web） |

## 必须覆盖的事件（14 天内至少各 1 次）

- [ ] 7 个连续自然日日常使用
- [ ] 3 个不同长度的真实会话（短/中/长）
- [ ] 2 台不同主机
- [ ] 1 次 DSH 重启（观察 session 失效后重新启动）
- [ ] 1 次设备吊销并重新配对（观察 WebView 立即失效）
- [ ] 1 次插件更新
- [ ] 1 次 App 升级安装
- [ ] 1 次低端机超长会话（≥500 条消息，滚动到底）

## 专门要观察的点

1. **键盘**：输入卡弹出、软键盘遮挡、发送后输入框状态
2. **长会话**：滚动性能、跳位、内存（App 是否被杀）
3. **审批**：手机审批允许/拒绝、Web 端先响应时的状态同步
4. **上传**：图片/文件/相机，DSH 实际收到
5. **通知**：通知点击打开正确主机+会话（深链桥）
6. **网络切换**：Wi-Fi 断开/恢复、DSH 重启
7. **桌面无感**：期间在电脑浏览器打开 DSH，确认桌面 UI 与改前完全一致（Gate 1 的承诺）

## 结束判定

- 满足全部阈值 + 覆盖事件 → 执行 Gate 6（归档原生工作台）
- 任一阈值不满足 → 默认切回 native（`WorkspaceEngine.set(ctx, "native")`），继续修 Web 主路径，不扩展原生功能
