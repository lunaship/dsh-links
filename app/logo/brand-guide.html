品牌标识指南 / Brand Identity Guide

主标识 / Primary Logo

全色版虎鲸图标，透明背景，适用于大多数场景。基于矢量绘制，可无损缩放至任意尺寸。

图标变体 / Icon Variations

根据不同背景和使用场景选择合适的版本。

全色版 / Full Color
反白版 / Reversed
黑色单色 / Mono Black
简化版 / Simplified

文字组合 / Logo Lockups

图标与品牌名称的组合排版，适用于正式场合。

横向组合 / Horizontal
竖向组合 / Stacked

色彩规范 / Color Palette

品牌标准色系，所有视觉物料应遵循此色彩规范。

安全空间 / Clear Space

标识周围需保留最小安全空间，确保视觉识别度。安全空间等于图标高度的 1/4。

虚线区域为最小安全空间，内部不可放置其他元素

最小尺寸 / Minimum Size

为确保辨识度，标识在不同场景下不应小于以下尺寸。小尺寸请使用简化版。

数字 / Digital: 120px
标准最小 / Min: 48px
Favicon: 24px (简化版)
极限最小 / 16px (简化版)

背景适配 / Background Usage

浅色背景使用全色版或黑色单色版；深色背景使用反白版。

使用规范 / Do's & Don'ts

正确使用品牌标识，保持一致的视觉形象。

✓ 正确
使用原始配色和比例
✗ 错误
不要更改原始配色
✓ 正确
深色背景使用反白版
✗ 错误
深色背景不要用全色版
✓ 正确
小尺寸使用简化版
✗ 错误
小尺寸不要用完整版
